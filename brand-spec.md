# Brand/spec do portfólio

## Direção

Editorial de ferramenta: racional, direto e orientado a evidências. O repositório deve parecer um case de produto interno, não uma página promocional genérica.

## Paleta

- Fundo: branco quente / cinza muito claro.
- Texto: grafite.
- Acento: vermelho-coral usado com parcimônia em indicadores e links.
- Estados: verde para sinal positivo, âmbar para atenção.

## Tipografia

Documentação em Markdown com hierarquia simples. Interface Streamlit usa a tipografia padrão do framework para reduzir dependências e manter o protótipo executável.

## Uso de marca

Nenhum logotipo oficial ou asset proprietário foi incluído. O nome iFood aparece apenas no contexto da candidatura e do benchmark fornecido pelo usuário. Caso o usuário queira publicar uma versão explicitamente co-branded, adicionar apenas assets oficiais autorizados.

## Regra editorial

Não usar métricas fictícias como resultados pessoais. Campos de impacto devem ser preenchidos após medição.
