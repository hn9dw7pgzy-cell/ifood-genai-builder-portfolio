# Como evoluir este portfólio

1. Troque os placeholders por dados pessoais e links reais.
2. Adicione screenshots somente com dados sintéticos ou anonimizados.
3. Para cada projeto, registre problema, hipótese, fluxo, stack, limitações e métrica.
4. Separe claramente benchmark, simulação e resultado medido.
5. Nunca comite `.env`, chaves de API, dados pessoais ou exportações de sistemas reais.
